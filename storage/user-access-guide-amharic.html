3.3 Two-Factor Authentication

2FA በsign-in ጊዜ ወይም በProfile > Security ታብ ውስጥ ይሰራል። QR code, setup key እና recovery codes ይቀርባሉ።

የስርዓቱ አጠቃላይ ቅንብር 2FA ካስገደደ ተጠቃሚዎች 2FA ሳይጨርሱ ስርዓቱን ማግኘት አይችሉም።
3.4 ከመግቢያ በኋላ የሚከሰት

  • Central ወይም tenant runtime context ይወሰናል።
  • Sidebar በpermission መሠረት ይሞላል።

7. የተለመዱ የተጠቃሚ ሂደቶች

4 Dashboard ውስጥ የሚታዩትን modules ይከፍቱ።

1 Security > Operators tab ይክፈቱ።

8. ችግኝ መፍትሄ

ችግኝ ሊሆን የሚችለው ምክንያት ፈጣን መፍትሄ ማስታወሻ
Login አይሳካምWrong credentials ወይም inactive accountኢሜይል/password ያረጋግጡ እና account status ይፈትሹ2FA redirect ካለ የሚቀጥለውን ገጽ ይመልከቱ
2FA code አይሰራምAuthenticator clock drift ወይም wrong accountየስልኩን ሰዓት ያመሳስሉ እና recovery code ይጠቀሙProfile Security ታብ ውስጥ እንደገና setup ሊፈልግ ይችላል
Module አይታይምPermission ወይም context ጉዳይRole እና assigned permissions ይፈትሹCentral-only modules tenant users አያዩም
Action button disabled ነውManage permission የለም ወይም item protected ነውAction-specific permission ይፈትሹExample: delete, archive, impersonate
Storage upload አይሳካምFile too large ወይም unsupported stateGeneral settings ውስጥ max upload ይፈትሹFolder permission እና network ሁኔታ ደግሞ ይፈትሹ
Alert dismiss አይሰራምmanage_alerts የለምRole ላይ permission ያክሉView-only users እንዲያዩ ብቻ ይችላሉ
